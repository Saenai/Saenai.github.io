## まず把握し、それから実行する

Microsoft To Do Safe MCP は、操作手順と MCP サービスのコードをスキルパッケージとしてまとめたものです。Microsoft To Do のバックアップ、分析、計画の検証、プレビュー、実行までのワークフローを提供します。

## 確認しながら進められる手順

1. バックアップを出力し、現在のタスク管理の状態を保存する。
2. タスクの整理方法と完了済みタスクのアーカイブを分析する。
3. 計画を提案し、検証して変更内容をプレビューする。
4. 操作手順に従って、確認済みの計画を実行する。

## ドキュメントからツールへ

スキルのディレクトリには、操作規則、インストールスクリプト、サービス実装をまとめています。公開リポジトリにはインストールと初期設定の方法に加え、バックアップ、分析、アーカイブ用の CLI も用意されています。

インストール手順と操作範囲は [リポジトリの説明](https://github.com/Saenai/microsoft-todo-safe-mcp#readme) をご確認ください。
