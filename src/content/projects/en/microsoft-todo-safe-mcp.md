## Understand first, then act

Microsoft To Do Safe MCP packages operating instructions and MCP service code as a skill, providing a workflow for Microsoft To Do that covers backup, analysis, plan validation, preview, and execution.

## A workflow you can inspect

1. Export a backup to capture a snapshot of the current task system.
2. Analyze task organization and completed-task archives.
3. Propose a plan, validate it, and preview its changes.
4. Follow the operating instructions to execute the confirmed plan.

## From documentation to tools

The skill directory contains operating guidelines, installation scripts, and the service implementation. The public repository documents installation and initialization, and also provides CLI entry points for backup, analysis, and archiving.

See the [repository documentation](https://github.com/Saenai/microsoft-todo-safe-mcp#readme) for installation steps and operational boundaries.
