## 先看清，再行動

Microsoft To Do Safe MCP 以技能套件的形式組織操作說明與 MCP 服務程式碼，圍繞 Microsoft To Do 提供備份、分析、計畫驗證、預覽與執行工作流程。

## 一條可檢查的處理路徑

1. 匯出備份，取得目前待辦系統的快照。
2. 分析任務組織方式與已完成任務的封存。
3. 提出計畫，驗證並預覽計畫的變更。
4. 依操作說明執行經確認的計畫。

## 從文件到工具

技能目錄同時容納操作規範、安裝指令碼和服務實作。公開儲存庫提供技能安裝與初始化方式，也保留了備份、分析和封存的 CLI 入口。

安裝步驟與操作範圍請參閱 [儲存庫說明](https://github.com/Saenai/microsoft-todo-safe-mcp#readme)。
