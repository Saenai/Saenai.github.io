## 先看清，再行动

Microsoft To Do Safe MCP 以技能包的形式组织操作说明与 MCP 服务代码，围绕 Microsoft To Do 提供备份、分析、计划校验、预览与执行工作流。

## 一条可检查的处理路径

1. 导出备份，获取当前待办系统的快照。
2. 分析任务组织方式与已完成任务归档。
3. 提出计划，校验并预览计划的变化。
4. 按操作说明执行经确认的计划。

## 从文档到工具

技能目录同时容纳操作规范、安装脚本和服务实现。公开仓库给出了技能安装与初始化方式，也保留了备份、分析和归档的 CLI 入口。

安装步骤与操作边界见 [仓库说明](https://github.com/Saenai/microsoft-todo-safe-mcp#readme)。
